# 双色球预测分析系统

> 我们曾试图从两千多期历史数据中打捞出规律。
>
> 我们追逐热号，守候冷号，计算遗漏、连号、共现网络和时间衰减；让 PageRank、蒙特卡洛、遗传算法轮番上阵，也试过避开所有人都看得见的“热门选择”。模型越来越复杂，回测曲线一度越来越漂亮，仿佛随机性的城墙终于出现了裂缝。
>
> 然而，当样本外数据到来，裂缝消失了。那些规律只是噪声留下的倒影，那些胜利只是过拟合替偶然写下的赞歌。
>
> **这个项目最终得到的最诚实结论是：双色球无法被历史数据稳定预测。**
>
> 我们没有找到通往开奖号码的密道。但我们保留了全部探索过程——不是为了继续兜售希望，而是为了证明：一个结论即使是否定的，只要经过认真验证，也值得被记录。

这是一个双色球历史数据分析与随机选号实验项目。它使用频率、遗漏值、图网络、蒙特卡洛采样、公众热度回避和历史回测等方法研究号码分布，但不声称能够提高任何合法号码组合的开奖概率。

## 项目结论

- 历史开奖可以被统计和描述，但不能据此稳定预测下一期。
- 热号、冷号、遗漏、邻号、结构和公众热度均未表现出可持续、可复现的样本外优势。
- 更复杂的模型更容易拟合历史噪声；回测中的短期领先不等于真实预测能力。
- 胆拖和组合优化只能改变预算分配与号码覆盖，不能改变开奖号码的概率。
- 本项目生成的任何号码都只适合娱乐和技术研究，不构成投注建议。

如果你仍决定购彩，请把它当作一次付费的随机游戏，而不是一项投资。愿望可以保留，生活不能押上。

- ✅ 历史数据分析（频率、热号、冷号、遗漏值、连号等）

## 快速开始

### 1. 安装依赖

```bash
pip install pandas numpy matplotlib requests beautifulsoup4 pillow python-dotenv
```

### 2. 爬取最新数据

```bash
# 检查最新期号
python fetch_history_v3.py --check

# 爬取最新数据
python fetch_history_v3.py --latest

# 全量爬取（首次运行）
python fetch_history_v3.py --start 10001 --end 26032
```

```bash
python predict_v4.py
```

预测结果保存在 `output/predictions_v4.json`

```bash
python lottery_ui_v1.2.py
```

## 算法说明

### 预测 v4 - 时间加权优化版

采用多维度综合评分体系：

| 因素 | 权重 | 说明 |
|------|------|------|
| 热号/冷号得分 | 50% | 多窗口频率分析 |
| PageRank | 25% | 号码网络核心度 |
| 区域分布 | 15% | 号码分区统计 |
| 遗漏加成 | 10% | 冷号回补建模 |

### 时间加权

| 周期 | 权重 |
|------|------|
| 短期 (近50期) | 60% |
| 中期 (51-200期) | 30% |
| 长期 (200期以上) | 10% |

### 图算法 (graph_predictor.py)

- **PageRank 算法**：分析号码在共现网络中的核心程度
- **号码共现矩阵**：统计号码同时出现的频率
- **聚类分析**：发现号码的热区冷区分布

### 蒙特卡洛采样

- 500次随机采样
- 精英选择策略
- 胆拖投注优化
